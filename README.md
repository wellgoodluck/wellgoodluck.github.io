# Economy in Context

An almanac of the main U.S. economic indicators, each shown against its own
history. Live at [economyincontext.org](https://economyincontext.org).

## How it works

- `index.html` is the whole site: one page, no framework, no cookies. The
  typeface (Public Sans, open license) is served from `assets/fonts/`. The one
  third-party request is the page-view count to GoatCounter
  (`assets/count.js`, a copy of GoatCounter's script, ISC license, from
  arp242/goatcounter commit c031008); it stores no IP addresses and skips
  framed pages, so chart embeds aren't counted.
- `chart.html` is the detail page: one indicator at full size
  (`chart.html?id=unemployment`), with optional overlays. Reference lines and
  companion series come from `data/companions.json`; eras (party control, Fed
  chairs, wars, QE) and dated events come from `data/overlays.json`, which is
  generated by `tools/make_overlays.py` and compiled by hand from primary
  sources. The overlays a reader turns on are kept in the URL, so any view can
  be linked.
- `articles/src/*.md` are the articles, Markdown with a short front-matter block
  (title, dek, date). `tools/build_articles.py` turns them into
  `articles/<slug>.html` and `articles/index.html` at publish time; the HTML is
  not kept in the repo. A line like
  `{{chart id=cpi range=10y ov=price_level caption="..."}}` embeds a live chart
  from the detail page. `assets/site.css` styles the articles.
- `fetch_fred.py` pulls the indicator set from the FRED API (Federal Reserve
  Bank of St. Louis) and writes `data/series.json` with the history, the latest
  reading, and context statistics (percentile in own history, 2015–19 average,
  typical range, record highs and lows), plus `data/companions.json` with the
  overlay series (PCE inflation, U-6, prime-age employment ratio, the CBO
  natural rate, continuing claims, single-family starts, wages, and derived
  spreads). It also maintains `data/firstprints.json`: each month's figure as
  first reported, from ALFRED (FRED's vintage archive). First prints never
  change, so the file is filled in a few hundred months per run and then only
  the newest month is fetched.
- `.github/workflows/refresh.yml` runs the fetch twice each weekday and
  publishes the result to GitHub Pages. It needs one repository secret,
  `FRED_API_KEY` (a free key from fredaccount.stlouisfed.org/apikeys).

To add or change an indicator, edit the `TILES` list at the top of
`fetch_fred.py`. The page reads whatever the JSON contains. Companion series
are the `COMPANIONS` and `DERIVED` lists in the same file. Eras and events are
edited in `tools/make_overlays.py`; party-control lanes need a two-line update
every other January after a new Congress is seated.

## Data

Source: FRED, Federal Reserve Bank of St. Louis. Underlying data from the
Bureau of Labor Statistics, Bureau of Economic Analysis, Census Bureau, Federal
Reserve Board, Freddie Mac and the National Bureau of Economic Research. All
figures are the current vintage and are subject to revision by the agencies.
